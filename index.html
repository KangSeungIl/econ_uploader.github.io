Shorts Uploader

Shorts Uploader는 운영자 본인의 유튜브 채널에 경제 해설 쇼츠 영상을 업로드하기 위한 개인용 도구입니다. 영상은 사람이 검수·승인한 뒤에만 YouTube Data API v3로 비공개 업로드되며, 공개 전환은 운영자가 YouTube Studio에서 직접 합니다.

Shorts Uploader is a personal tool that uploads human-reviewed short videos to the operator's own YouTube channel via the YouTube Data API v3. Videos are always uploaded as private.

사용하는 Google 권한 / Google data used

  • https://www.googleapis.com/auth/youtube.upload — 운영자 채널에 동영상 업로드 / upload videos to the operator's channel
